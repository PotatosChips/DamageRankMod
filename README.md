# DamageRankMod

`FH_DamageRankMod` 是一个用于《Slay the Spire 2》的伤害统计与排行模组。  
它会在战斗中显示队伍成员的伤害面板，帮助你更直观地查看本场贡献和全局累计表现。

## 功能介绍

- 实时显示伤害排行榜（按本场伤害排序）。
- 显示每位玩家的：
  - 本场伤害
  - 本场占比
  - 累计总伤害
- 显示全队本场总伤害与累计总伤害。
- 统计数据可跨战斗保存，重启游戏后仍可继续累计。

## 如何加入模组

### 1) 首次添加 Mod：创建目录

如果你是第一次给游戏加模组：

1. 在 Steam 中找到游戏本地文件（浏览本地文件），进入游戏根目录。
2. 在根目录下新建 `mods` 文件夹（如果已存在可跳过）。
3. 在 `mods` 内再新建一个模组文件夹，例如：`DamageRankMod`  
   （文件夹名称可自定义，建议使用英文）。

### 2) 复制构建产物

将本项目 `build` 目录中的以下文件复制到你刚创建的模组文件夹中：

- `*.dll`
- `*.pck`
- `*.json`

也就是把 `build` 里对应的三个模组文件放进 `mods/DamageRankMod/` 即可。

### 3) 首次加 Mod 后的存档处理（重要）

游戏会把“加模组”和“不加模组”的存档分开。  
因此第一次启用 Mod 时，看起来会像“重新开始”。

如果你想继续使用原来的存档，请按下面操作迁移：

1. 按 `Win + R`，输入 `%appdata%` 并回车。
2. 找到 `SlayTheSpire2\steam\..\` 下的 `profile1` 文件夹。
3. 将 `profile1` 复制到 `modded` 文件夹里。
4. 如果没有 `modded` 文件夹，就在 `profile1` 同级目录手动新建一个 `modded`，再把 `profile1` 复制进去。

完成后，进入 Modded 存档即可继续原进度。
